# Greeting App

A tiny, self-contained web app that asks for your name and shows a `Hello <name>!` popup when you click **Submit**.

## Features

- Name input with empty-input validation
- Submit button opens a custom modal popup
- Press **Enter** to submit
- Close the popup via the **OK** button or by clicking the overlay
- XSS-safe: user input is escaped before rendering

## Run

No build step or dependencies. Just open `index.html` in any modern browser.
